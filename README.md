# 01_Microcontroller-Based-Variable-Racing-CDI-Modules-2021-

Here is special version of ZTS ARMAGEDON DC CDI based arduino nano mcu code.
This cdi has 15k rpm (devided by) 60 steps ignition map, 2 selectable rev limiter, and 2 selectable map for other driving mode.
To tunning it u can remake the ignition timing maps with array 1 dimension or u can copy/paste it from IGN_MAP.ino file. there is a lot maps but its limited by indonesian fuels compression ratio.
Before u attach it to your engine please watch about PULSE value. Match it with your pulse sens leght on your engine.
Im using 58 as a default value cause my (F1ZR) pulse sens has 57.5mm leght and i keep the 0.5mm to minimalize R&D risk.
U can try it if u like performace on your engine
